# AutoNav Sim — Phase 0 (Cleanup) + Phase 1 (Robot-Profile Foundation) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Clean the public-facing cruft out of `autonav_sim`, then introduce a config-driven **robot profile** so the simulator's robot *identity* (Gazebo model name and the `/model/<name>/odometry|tf` topics) is no longer hardcoded to `shogi` — with the default profile reproducing the current sim byte-for-byte.

**Architecture:** A new pure-Python module `robot_profile.py` (no ROS imports, unit-testable) loads a `profile.yaml` into a frozen `RobotProfile` dataclass that derives the Gazebo odom/tf topic names from `name`. World generation, the sensor harness, the odom bridge, and the launch file all consume the profile instead of the literal string `shogi`. The default profile (`profiles/shogi/profile.yaml`, `name: shogi`) keeps every generated artifact and topic identical to today, enforced by a golden test and the existing `_validate_world_sync` launch gate.

**Tech Stack:** ROS 2 Humble, Gazebo Fortress (Ignition), Python 3.10, PyYAML, pytest, colcon, git. Runtime ROS nodes are smoke-tested in the existing limactl CPU VM (no Jetson/GPU required).

## Global Constraints

_Every task's requirements implicitly include this section._

- **ROS 2 Humble + Gazebo Fortress (Ignition)**; Python 3.10; ament_python package `igvc_competition_sim`.
- **Behavior-preservation invariant:** with the default profile (`name: shogi`), `generate_world(...)` MUST produce a normalized string byte-identical to the committed `igvc_competition_sim/worlds/igvc_competition_compact.sdf`. Normalization = `"\n".join(line.rstrip() for line in text.splitlines()) + "\n"` (matches `generate_world.main()` and `_validate_world_sync`).
- **Profile `name` regex:** `[A-Za-z0-9_]+` (it becomes a Gazebo model name and is interpolated into `/model/<name>/odometry`).
- **No absolute user paths** (`/Users/...`, `/home/cole...`) in tracked files **outside** `igvc_competition_sim/autoresearch/` (that subtree is deferred to the Phase 4 plan).
- **Git history is NOT rewritten** (spec decision D7). Remove tracked artifacts with `git rm --cached` + `.gitignore`; the working files stay on disk.
- **Pure-logic tests** (`robot_profile.py`, `generate_world.py`, `course.py` — none import `rclpy`) run with `cd igvc_competition_sim && python -m pytest test/<file> -v`. **ROS-runtime nodes** (`sensor_harness.py`, `odom_bridge.py`, `igvc_competition.launch.py`) cannot be imported without a sourced ROS env; they are verified by the VM smoke test in Task 1.6, plus a grep/AST check at edit time.
- **Commit after every task.** Use `git` on the existing `showcase-restructure` branch.

## Scope Boundary (what this plan deliberately does NOT do)

Locked in during planning, to keep this increment reviewable:
- **Robot geometry/dynamics stay in the course YAML** (`robot:` block, read via `course.robot` by `generate_world.py`, `course_monitor.py`, `sensor_harness.py`). Migrating geometry into the profile is a **follow-up Phase 1b plan**.
- **Camera/ZED topic names + intrinsics, robot mass/inertia/meshes, the `zed2i_rgbd` sensor block** stay hardcoded for now (Phase 1b).
- **The bundled minimal robot** is Phase 2; **AutoNav profile in `AutoNav_25-26`** is Phase 3; **autoresearch generalization** is Phase 4.
- The autoresearch course worlds (`autoresearch/courses/worlds/*.sdf`) and `autoresearch/lib/validate_course.py` (which hardcodes `name == "shogi"`) are **not** touched here; they only matter once non-shogi profiles drive autoresearch (Phase 4). The `.command` launchers (`Run_*_TEST.command:136`) are regenerated in the Phase 2 launcher work.

```python
from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path
import re
from typing import Any

import yaml

PACKAGE_ROOT = Path(__file__).resolve().parents[1]
_DEFAULT_PROFILE_NAME = "shogi"
_VALID_NAME = re.compile(r"[A-Za-z0-9_]+")


def _default_robot_profile() -> Path:
    source_tree = (
        PACKAGE_ROOT / "profiles" / _DEFAULT_PROFILE_NAME / "profile.yaml"
    )
    if source_tree.is_file():
        return source_tree
    try:
        from ament_index_python.packages import get_package_share_directory
    except ImportError:
        return source_tree
    return (
        Path(get_package_share_directory("igvc_competition_sim"))
        / "profiles" / _DEFAULT_PROFILE_NAME / "profile.yaml"
    )


DEFAULT_ROBOT_PROFILE = _default_robot_profile()


@dataclass(frozen=True)
class RobotProfile:
    """Identity of the robot the sim spawns and bridges.

    For now this carries only the Gazebo model ``name``; geometry/dynamics
    still live in the course config (see the Phase 1b plan).
    """

    name: str
    description: str = ""

    @property
    def gz_odom_topic(self) -> str:
        return f"/model/{self.name}/odometry"

    @property
    def gz_tf_topic(self) -> str:
        return f"/model/{self.name}/tf"


def load_robot_profile(path: str | Path | None = None) -> RobotProfile:
    profile_path = Path(path) if path else DEFAULT_ROBOT_PROFILE
    raw: Any = yaml.safe_load(Path(profile_path).read_text(encoding="utf-8"))
    data = raw or {}
    if not isinstance(data, dict):
        raise ValueError(
            f"robot profile {profile_path} must be a YAML mapping")
    name = str(data.get("name", "")).strip()
    if not name:
        raise ValueError(
            f"robot profile {profile_path} missing required 'name'")
    if not _VALID_NAME.fullmatch(name):
        raise ValueError(
            f"robot profile name '{name}' must match [A-Za-z0-9_]+ "
            "(it becomes the Gazebo model name and /model/<name>/odometry)")
    return RobotProfile(name=name, description=str(data.get("description", "")))
```
